## 🚀 Quick Installation (2 Minutes)

### Step 1: Upload Theme
1. **Zip the theme folder**: Select all files in `artsplans-wp-theme` folder and create a zip file
2. **Login to WordPress Admin**: Go to your website's WordPress admin panel
3. **Navigate to Themes**: Go to `Appearance → Themes`
4. **Add New Theme**: Click `Add New` then `Upload Theme`
5. **Choose File**: Select your zip file and click `Install Now`
6. **Activate**: Click `Activate` once installation is complete

### Step 2: Import Demo Content (Optional but Recommended)
1. **Install WordPress Importer**: Go to `Tools → Import` → Install WordPress Importer
2. **Import Demo Content**: Upload the `demo-content.xml` file
3. **Import Settings**: 
   - ✅ Download and import file attachments
   - ✅ Import authors (or assign to existing user)
4. **Run Import**: Click `Submit` and wait for completion

### Step 3: Configure Menus
1. **Go to Menus**: Navigate to `Appearance → Menus`
2. **Create Primary Menu**: Add pages like Browse, Categories, Upload, About
3. **Assign Menu Location**: Set as "Primary Menu" location
4. **Save Menu**: Your navigation is now set up

## 🚨 Troubleshooting

### Common Issues & Solutions

#### Theme Not Installing
```
Problem: Upload failed
Solution: 
1. Check file size limits
2. Ensure proper zip structure
3. Try uploading via FTP
```

#### Demo Content Not Importing
```
Problem: Import fails
Solution:
1. Install WordPress Importer plugin
2. Increase memory limit
3. Import in smaller batches
```

#### Styling Issues
```
Problem: Layout looks broken
Solution:
1. Clear any caching plugins
2. Check for theme conflicts
3. Ensure Tailwind CSS is loading
```

#### Search Not Working
```
Problem: AJAX search fails
Solution:
1. Check JavaScript console for errors
2. Verify AJAX URL in functions.php
3. Test with default WordPress search
```
