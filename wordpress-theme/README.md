# ArtsPlans WordPress Theme

A complete WordPress theme that replicates your interior design platform with all the functionality from your React application.

## Quick Installation

1. **Download** all files from the `wordpress-theme` folder
2. **Zip** the entire `wordpress-theme` folder
3. **Upload** to WordPress:
   - Go to WordPress Admin → Appearance → Themes
   - Click "Add New" → "Upload Theme"
   - Select your zip file and click "Install Now"
   - Click "Activate"

## After Installation

### 1. Set Up Menus
- Go to Appearance → Menus
- Create menus for Primary, Footer, and Mobile locations
- Add pages like Browse, Categories, Shop, etc.

### 2. Configure Theme
- Go to Appearance → Customize
- Set your logo, colors, and hero section content
- Configure social media links

### 3. Add Content
- Create Floor Plans and 3D Models
- Add Design Categories
- Set up your product pages

### 4. Test Functionality
- Test the search functionality
- Verify navigation works
- Check responsive design on mobile
